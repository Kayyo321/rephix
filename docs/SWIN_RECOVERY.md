# Recover Swin and Swin V2 classifiers

`recover-layers` supports native Transformers Swin and Swin V2 image classifiers. The chosen probes cover the patch convolution, attention and MLP matrices, normalization layers, classification head, and learned relative position state. The export includes the source image processor configuration.

```sh
rephix --threads 2 recover-layers --model /path/to/source --output /path/to/recovered \
  --device cpu --dtype float64 --batch-size 512 --evidence-dir /path/to/evidence
rephix replay-layers --evidence-dir /path/to/evidence --output /path/to/replayed
```

Swin V1 stores a learned relative position bias table and an integer index buffer. The table probe chooses row IDs for the native lookup. The index probe substitutes a coordinate-labelled table into that lookup and observes which rows the native index selects. This recovers every valid nonnegative index, including modified indices. The adapter rejects negative indices because equivalent Python indexing would hide their original signs. Both the table and persistent index are captured in the evidence journal.

Swin V2 computes relative position biases with affine MLP layers and stores a learned attention logit scale. Its native forward clamps that scale before exponentiation. The scale probe chooses a clamp bound large enough to expose every finite stored scale, then observes the clamp output before exponentiation. A synthetic regression uses scales above the ordinary clamp limit. The position coordinates and index in Swin V2 are nonpersistent buffers regenerated by the native configuration.

These observations require instrumented access to the native operators. The tested classifiers use their standard relative position configuration. The synthetic tests modify Swin V1's persistent indices and verify that export and replay preserve them.

The published trials used CPU FP64 probes and inference with PyTorch 2.10.0 and Transformers 4.57.6. An independent audit compared every original stored tensor by name and shape, including Swin V1's persistent index buffers, with tolerance `abs(candidate - reference) <= 1e-8 + 1e-5 * abs(reference)`. Each comparison covered every original value. [Full checkpoint hashes and measurements](../examples/results/swin-layer-recovery.json)

The evaluator loaded each source and export independently. It compared full classifier logits on eight native-size random images, eight rectangular random images, and a public COCO image processed by each checkpoint's native image processor. The processors produced identical pixels for the public image. The pinned Swin V2 release provides a PyTorch archive, so the reference was loaded with `torch.load(weights_only=True)` and serialized to safetensors. Every tensor name, shape, dtype, and value was verified unchanged. The report records both archive hashes. [Public image source](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/coco_sample.png)

Replay rebuilt both checkpoints with the original source paths absent and consumed only saved observations. The weights, configuration, and processor files matched the initial exports byte for byte. Focused tests also passed with Transformers 4.46.0.

```sh
python examples/vision_recovery_experiment.py \
  --reference /path/to/source --candidate /path/to/recovered \
  --model-id "$repo" --revision "$revision" --image /path/to/coco_sample.png \
  --device cpu --threads 2 --output /path/to/results.json
```
