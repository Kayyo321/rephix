# Checkpoint recovery with chosen inputs to individual layers

A [persistent session](SESSIONS.md) learns behavior from text or tool traces. [Dense token log probabilities](LOGIT_SUBSPACE.md) reveal an output contrast subspace under favorable rank and precision conditions. Direct, coordinate-preserving layer calls can recover a full checkpoint when the architecture and parameter ties are known and all parameterized operators have probes.

## Recover and audit a local checkpoint

```bash
pip install -e '.[hf]'
rephix --threads 4 recover-layers \
  --model models/reference --output runs/recovered --device cuda
rephix audit-weights models/reference runs/recovered --output runs/weight-audit.json
```

The source must be a local Hugging Face Transformers directory with `config.json` and safetensors. The export includes the architecture, generation configuration, tokenizer, and recovered weights. The estimator creates a fresh model and receives only layer outputs. The local adapter loads the reference to serve those calls. Python callers with a separate instrumented runtime can use `rephix.layer_recovery.recover_from_layer_calls(skeleton, call_layer)` directly. The callback receives a module path and a batch of chosen inputs and returns full outputs in that layer's original coordinates.

- An affine layer exposes its bias at zero. Probing scaled basis vectors and subtracting that bias yields the matrix coefficients. Biasless layers use unit basis vectors.
- An embedding lookup exposes one row per token ID.
- Normalization scale and bias follow from a known normalized input and, for LayerNorm with bias, the zero-input output.
- Tied parameters are recovered once and remain tied in the export. Config-defined nonpersistent buffers are regenerated by Transformers.

The implemented decoder probes cover standard dense Llama, Mistral, Qwen, GPT-2, GPT-NeoX, GPT-J, BLOOM, Falcon, OPT, Phi, OLMo, and Gemma text checkpoints. Sparse PhiMoE and OLMoE also use individually callable affine router and expert layers. Recovery rejects custom model code, unsupported parameterized operators, and unsupported persistent state in the destination skeleton. Separate guides cover [native vision-language checkpoints](VLM_RECOVERY.md) and [quantized GGUF layouts](GGUF_RECOVERY.md). A source may contain legacy serialized tensors that its Transformers loader ignores.

OPT's position lookup accepts signed logical indices to expose its two reserved rows. The Gemma 3 text adapter calls the native unscaled embedding lookup before the model's fixed output multiplier. Gemma offset RMSNorm exposes the FP32 gain `1 + weight.float()`. When adjacent stored weights produce the same gain, Rephix reports the ambiguous coordinates and writes a representative with that gain. OLMo 2 and 3 multiply by the stored weight directly. Their RMS probes use a constant input whose normalized value is one, with an output dtype that can represent the stored scale exactly.

### Sparse decoder probes

- GraniteMoE, GraniteMoE Shared, and JetMoE expose their packed affine banks by assigning all probe rows to a chosen expert. DBRX and dense GPT-OSS expose intermediate native matrix products with a controlled expert ID and an independently chosen input for the down projection.
- DeepSeek V2, DeepSeek V3, and GLM4-MoE expose router logits before top-k selection. DeepSeek V3 and GLM4-MoE also expose the persistent routing correction by adding it to zero scores. The native logit computation casts to FP32, so FP64 router coordinates are reported as ambiguous.
- GPT-OSS sink logits are observed before attention softmax. This adapter takes dense floating-point checkpoints. Packed MXFP4 archives have a separate weight representation.
- Qwen3-MoE uses directly callable expert and router layers. Jamba combines sparse layers with the [native recurrent state probes](SSM_RECOVERY.md).

The default FP32 probes reduce rounding loss in biased layers. For a large BF16 checkpoint use `--dtype auto` to preserve its runtime dtype and reduce RAM and VRAM needs. By default the source lives on the requested device and the candidate stays in CPU memory. Use `--stage-layers` to keep the source on the host and move each probe's dependencies to the accelerator in turn. `--batch-size` trades call overhead for temporary memory. In these experiments the oracle returned one scalar per unique parameter. An instrumented runtime needs access roughly as revealing as a weight dump. Checkpoints that require SentencePiece tokenizer conversion may need `pip install sentencepiece protobuf` and the source's tokenizer model. Use `--without-tokenizer` when exporting an offline model fixture consumed via token IDs. [Layer staging and memory measurements](LAYER_STAGING.md)

`audit-weights` streams local safetensors files or standard indexed shard directories. A reference element matches when its candidate has the same name and shape and `abs(candidate - reference) <= atol + rtol * abs(reference)`. Defaults are `atol=1e-8` and `rtol=1e-5`. Exact agreement counts equal numeric values, even across differing storage dtypes. Coverage and both agreement fractions use all stored reference elements, including buffers. Raw relative L2 is `||candidate - reference||₂ / ||reference||₂` and requires full name and shape coverage. The separate zero-filled score substitutes zeros for unavailable coordinates. Extra candidate tensors are reported and excluded from the scores. The audit does not remap names, align equivalent parameters, or infer tied aliases. Use the existing `compare-weights` command when comparing the loaded model's named parameters and cosine similarity.

## Resume and replay layer probes

Pass `--evidence-dir` to save each complete probe response as it arrives. Keep the source checkpoint available for interrupted captures and repeat the same command to continue. Rephix verifies the source files and probe settings, then reuses committed responses in order. If a process stops before committing a response, the next run queries that position again. The output directory must be new, and the source, evidence, and output directories must be separate.

```bash
rephix --threads 4 recover-layers --dtype auto --batch-size 256 \
  --model reference --evidence-dir probes --output recovered
rephix --threads 4 replay-layers --evidence-dir probes --output replayed
```

Once the last observation is committed, Rephix seals the bundle before exporting the checkpoint. A sealed bundle can rebuild the checkpoint even if the first export was interrupted or the source has been deleted. It contains a checksummed observation database and the saved model configuration, plus the selected tokenizer or preprocessor assets. Replay verifies that the complete probe sequence is present and consumes it without making oracle calls. Replay reconstructs the model on CPU. T5-family attention-only bias probes and Mamba decay probes also need the original oracle device backend for their numerical transforms.

The evidence database stores responses at the original observation precision and can be about as large as the source weights. Allow room for both the bundle and the exported model. The report distinguishes `evidence_observations_cached` from `evidence_observations_collected` for the current invocation.

### Forced-stop trials

Two CPU captures were terminated with `SIGKILL` after 17 committed responses and before the next probe. Each resumed with its original settings, and the source directory was deleted before offline replay. The resumed exports matched all 17,253,120 original stored values exactly. ## Why an endpoint cannot guarantee 95% raw weight agreement

Consider a biasless Llama or Mistral decoder with RMSNorm and gated MLPs. Negate its input embedding, every attention and MLP matrix, and its output projection. Keep the RMSNorm weights. A tied embedding and head are negated once.

For every token, the residual stream is negated. RMSNorm is odd, so its output is negated as well. The negated input and negated Q, K, and V matrices cancel, leaving Q, K, and V unchanged through rotary embeddings, attention, and the KV cache. The negated attention output matrix produces a negated residual update. The two MLP input projections cancel the input sign, leaving the gated product unchanged. The negated down projection negates the MLP update. By induction, the final hidden state is negated, and the negated head cancels that sign to produce the original logits for every input. The argument holds in real arithmetic. The trials below check the same construction in the model's inference dtype.

A candidate coordinate can pass the tolerance for both checkpoints only if their tolerance intervals overlap. Where those intervals are disjoint, a candidate can match at most one checkpoint. If a fraction `s` of intervals overlap, one of the two agreement fractions is at most `(1+s)/2`. For the measured models that bound is close to 50%. Even a perfect endpoint oracle cannot identify which of the two raw checkpoints generated the observations. A parameter score therefore requires additional evidence or a declared convention for equivalent coordinates. Published black-box extraction of the output projection also recovers it only up to symmetries. [Carlini et al., ICML 2024](https://proceedings.mlr.press/v235/carlini24a.html)

The two checkpoints have equal norms. By the triangle inequality, a candidate's relative L2 error against at least one of them is at least half the distance between them. The measured distances exceed 0.1, so a relative L2 target of 0.05 is also impossible to guarantee from endpoint evidence.

## Pretrained experiments

The recovery trials used PyTorch 2.10.0+cu128 and Transformers 4.57.6. Pythia ran on CPU. The other trials used an RTX 5080. They used no natural-language training data. The evaluation reloaded the exported checkpoint independently and compared full-vocabulary next-token logits on 24 prompts across six families. It also compared greedy continuations up to eight tokens on six of those prompts. The report records pinned model revisions, file hashes, counts, evaluation prompts, and raw metrics. ## Dense log probabilities on Llama and Mistral

The [dense subspace protocol](LOGIT_SUBSPACE.md) also ran on TinyLlama-15M and Lite-Mistral-150M-v2-Instruct. The fit received 1,536 prompt rows and 1,153 fixed token log-probability coordinates per row. Another 192 prompts from different template families were held out. For prediction, each held-out query supplied 1,001 anchor scores, including the reference token. The fit then predicted the other 152 log odds. [Dense subspace measurements](../examples/results/cross-family-logit-subspace.json)

| Reference | Recovered rank / evaluator width | Projection operator error | Held-out anchor RMSE | Top-1 among 152 predicted coordinates |
| --- | ---: | ---: | ---: | ---: |
| TinyLlama-15M | 288 / 288 | `9.68e-5` | `4.37e-5` nats | 192/192 |
| Lite-Mistral-150M-v2-Instruct | 768 / 768 | `5.62e-5` | `8.32e-5` nats | 192/192 |

With only 128 fitting prompts, both models hit the rank ceiling of 127 and produced larger held-out projection errors. Rounding scores to three decimal places inflated the measured rank. The reference token appeared in none of the captured top-20 lists, so that observation contract could supply none of the fixed-reference log odds directly. These results identify output contrast geometry in the selected token coordinates. The sign control establishes why that geometry cannot determine the original checkpoint.

## Reproduce a run

Download a pinned source revision into a disposable directory on a disk with room for the reference and export. For Mistral-7B the two BF16 checkpoints together need about 29 GB of disk. A RAM-backed temporary filesystem may be too small.

```bash
mkdir -p runs
scratch=$(mktemp -d -p "$PWD/runs" rephix-trial-XXXXXX)
trap 'rm -rf -- "$scratch"' EXIT
export HF_HOME="$scratch/hf-cache"
export HF_XET_CHUNK_CACHE_SIZE_BYTES=0
repo=nickypro/tinyllama-15M
revision=a97e01fa7d54c088df9dc1b53d581a863ce08cd6

hf download "$repo" config.json generation_config.json model.safetensors \
  tokenizer.json tokenizer_config.json special_tokens_map.json \
  --revision "$revision" --local-dir "$scratch/reference"
rephix --threads 4 recover-layers --device cuda \
  --model "$scratch/reference" --output "$scratch/recovered"
python examples/layer_recovery_experiment.py --device cuda \
  --reference "$scratch/reference" --candidate "$scratch/recovered" \
  --model-id "$repo" --revision "$revision" --output runs/tinyllama-layer-audit.json
```

The evaluator's `--repack-reference` option adds a separate audit after loading and saving the reference with the current Transformers version. The original file audit or its error remains in the report. GPT-2 and Pythia used repacking for legacy serialization. For Mistral-7B, download both `model-0000*-of-00002.safetensors` files and their index, use `--dtype auto --batch-size 256`, and include `tokenizer.model` if the tokenizer requires it.
